# Reserva de un asiento en sala de cine

## Autor
Gixon Pinargote

## Descripción

Este proyecto corresponde a la actividad de la Semana 12 sobre arreglos N-Dimensionales e iteración sobre arreglos multidimensionales utilizando bucles anidados.

El programa permite reservar un asiento en una sala de cine de 3 filas por 4 columnas, para un total de 12 asientos.

Cada asiento se representa mediante un valor numérico:

- 0 = asiento libre
- 1 = asiento reservado

El usuario ingresa la fila y la columna del asiento que desea reservar. El programa registra la reserva y posteriormente muestra el estado completo de la sala.

## Objetivo

Aplicar los conocimientos sobre:

- Listas de listas en Python.
- Arreglos bidimensionales.
- Índices de filas y columnas.
- Modificación de elementos de una matriz.
- Bucles for anidados.
- Entrada de datos mediante input().
- Conversión de datos mediante int().
